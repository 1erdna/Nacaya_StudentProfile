# Nacaya_StudentProfile - Activity 4

## 1. Project Description
This application is a multi-page Student Profile built with HTML5, CSS3, and Apache Cordova. Converted from a single-page portfolio, it presents academic details, hospitality-to-tech career background, technical skills, projects, and contact details.

## 2. Application Pages
* **Profile (index.html):** Homepage featuring profile summary, title, and quick call-to-action buttons.
* **About (about.html):** Personal introduction, hospitality career transition details, education background at Xavier University - Ateneo de Cagayan, and certifications.
* **Skills (skills.html):** Breakdown of technical tools categorized across Frontend, Backend, Mobile & Data, and Workflow tools.
* **Projects (projects.html):** Showcase of 4 key software projects (Quench POS, N-Insights Xmas, PingPongPro, Library Reserve) including developer roles and technology stacks.
* **Contact (contact.html):** Direct channels including email, phone number, GitHub profile link, and location.

## 3. Navigation
Navigation is implemented strictly using basic HTML anchor tags (`<a href="...">`) across a unified header navigation bar without using JavaScript routing or dynamic page generation.

## 4. Responsive Design
Styled using standard CSS Flexbox, Grid, and `@media (max-width: 640px)` media query rules to ensure proper readability and layout behavior across Mobile, Tablet, and Desktop screens.

## 5. UI/UX Principles Applied
* **Consistency:** Dark background palette (`#030303`), uniform glassmorphic card elements, font typography, and pill header navigation.
* **Visual Hierarchy:** Standout linear-gradient page headings, bolded badges, and muted text for supporting details.
* **Usability:** Distinct visual highlight state on active navigation links to ensure the user always knows their current page.
