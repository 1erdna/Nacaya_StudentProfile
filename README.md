# Student Profile Application (Activity 3)

## 1. Project Description
This application is a responsive, single-page Student Profile built for **Andrei Jullian Nacaya**. The application showcases personal background, education, computing interests, and technical skills. It has been optimized using UI/UX design principles to ensure a seamless experience across desktop, tablet, and mobile screen sizes.

---

## 2. Application Structure
The application consists of five main layout structural blocks:
* **Header:** Displays the student profile picture, full name (`Andrei Jullian Nacaya`), and subtitle.
* **Navigation Menu:** Contains accessible intra-page anchor links (`About` and `Skills`) fixed to the header area.
* **About Section:** Features an introductory overview, academic details, personal interests, and career goals.
* **Skills Section:** Displays a structured grid highlighting 5 core technical competencies along with detailed descriptions.
* **Footer:** Displays copyright details, author name, current year (`2026`), and a back-to-top anchor link.

---

## 3. Responsive Design
The layout was designed using modern CSS techniques (Flexbox, CSS Grid, Media Queries, and Mobile-First breakpoints) to fluidly adapt to varying viewport dimensions without requiring horizontal scrolling or causing text distortion:
* **Mobile (< 600px):** Single-column stacked orientation with touch-friendly navigation links.
* **Tablet (600px - 1024px):** Two-column card grid and aligned horizontal header layout.
* **Desktop (> 1024px):** Multi-column grid layout utilizing expanded screen space with sticky section labels.

---

## 4. UI/UX Principles Applied
* **Responsive Layout:** Dynamic grid columns and flexible container widths prevent horizontal overflow across viewports.
* **Mobile-Friendly Spacing:** Standardized CSS variables for padding and margins establish consistent whitespace and touch targets (minimum 44px height).
* **Appropriate Typography:** Clear font sizing scale (`system-ui` font stack) ensures readability across all screen densities.
* **Clear Visual Hierarchy:** Distinct heading sizes, font weights, and high-contrast color tones highlight key profile sections.
* **Usable Controls:** Styled navigation links feature distinct hover and focus states for easy identification and navigation.
* **Basic Accessibility:** High contrast text-to-background ratios, semantic HTML tags, and descriptive `alt` tags on profile imagery.
* **Consistent Design:** Unified color palette (`#1e3a8a` primary blue tones) applied across buttons, borders, and headers.

---

## 5. Navigation
The `About` and `Skills` navigation links utilize pure HTML fragment identifiers (`href="#about"` and `href="#skills"`). Clicking a link smoothly scrolls the page to the corresponding section header within the same page. **No JavaScript is used.**
